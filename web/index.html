Pay on proof.

A requester posts 50 jobs: hash a file range, sort a shard, solve a small system. Two workers take them. One is honest; the other is rigged to return a wrong answer about one time in ten. A cheap verifier checks every result. Only a pass gets a signed, single-use reward token.
